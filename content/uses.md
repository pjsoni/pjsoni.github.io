Read on to get a look at the hardware and software I use for development, experimentation, photography, and maintaining this website. None of it is particularly exotic, but if you're curious about what goes on behind the scenes, you might find it interesting.

## Design and Development

My development environment changes over time, but the tools I currently use include:

* **Operating systems:** macOS and Windows
* {{< external-link >}}**[Visual Studio Code](https://code.visualstudio.com/)**{{</ external-link >}} and {{< external-link >}}**[VSCodium](https://vscodium.com/)**{{</ external-link >}}
* **Git** for source control
* {{< external-link >}}**[Hugo](https://gohugo.io/)**{{</ external-link >}} as the static site generator

Some of the Visual Studio Code extensions I find useful include:

* {{< external-link >}}**[Grammarly](https://marketplace.visualstudio.com/items?itemName=znck.grammarly)**{{</ external-link >}}
* Write Good Linter
* Insert Date String
* Lorem ipsum
* Code Spell Checker
* CSS Var Complete

I got interested in static site generators after discovering {{< external-link >}}[Jekyll](https://jekyllrb.com/){{</ external-link >}}. These days, I use {{< external-link >}}[Hugo](https://gohugo.io/){{</ external-link >}} together with a custom theme to build this website.

The basic idea is simple: I write the site's content in Markdown, Hugo processes the content and templates, and the resulting static files are deployed to the web.

This approach keeps the site relatively simple, fast, and easy to maintain while giving me complete control over the content and presentation.
